## 推荐提交组合

1. 方案附件：优先上传 `MateClaw智能排障-作品方案.pdf`，需要继续编辑时使用 DOCX
2. 流程讲解：`MateClaw智能排障-可演示流程图.html`，使用“下一步”或自动演示逐节点介绍
3. Demo：`MateClaw智能排障-作品介绍.html`
4. 效果图：`assets/` 下三张 PNG
5. 系统实操视频：优先使用 `MateClaw智能排障-真实系统操作演示.mp4`
6. 方案讲解视频：需要完整介绍接入保障、作品方案和投产边界时，使用 `MateClaw智能排障-作品演示.mp4`

## 推荐讲解顺序

1. 先讲三个真实问题：二线如何开始排障、三线如何降低陌生系统的上手门槛、重大故障如何快速收敛范围。
2. 再讲三种处理方式：已审核方法直接执行、新问题结案后审核沉淀、无方法时受限只读探索。
3. 然后展示 ITGW 904003 真实案例，证明一条已审核方法确实能在真实 Guance 数据上运行。
4. 最后说明人员效果怎样验收，再进入技术实现与投产边界。

## 口径边界

- 已证明：一条 `CSDP / csdp-wechat / 904003` 场景可在真实 Guance 上完成三次只读查询、确定性判断和双投影展示。
- 上述真实案例证明的是“方法能跑”，不等于已证明二线独立完成率、三线新人上手效率或重大故障收敛耗时已提升；这三项必须通过真实人员试用验收。
- 尚未证明：平台已覆盖全部系统、达到正式批次录制目标、具备通用未知场景自主规划能力或可以自动执行生产变更。
- 平台定位：辅助人更快获得可复核证据；生产处置始终由授权人员在系统外执行并登记结果。
