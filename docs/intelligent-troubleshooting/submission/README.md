# MateClaw 智能排障作品提交包

本目录是一套可以直接用于作品介绍、评审讲解和现场演示的材料。所有已完成能力均以当前真实系统和 `ITGW访问失败【904003】` 真源案例为依据；未完成能力单独列为投产计划，不以 Demo 数据冒充。

## 提交材料

| 材料 | 用途 |
| --- | --- |
| `MateClaw智能排障-作品方案.docx` | 正式项目方案文档，含场景、方案、AI 工具使用、效能提升、真实验证和投产计划 |
| `MateClaw智能排障-作品方案.pdf` | 可直接预览或上传的固定版式方案文档 |
| `MateClaw智能排障-作品介绍.html` | 可离线打开的作品介绍与 Demo 导览页 |
| `MateClaw智能排障-作品方案正文.md` | 方案正文源文件，便于继续维护和复制到报名系统 |
| `MateClaw智能排障-演示视频脚本.md` | 4 分钟演示视频脚本、镜头和讲解词 |
| `assets/01-排障结果总览.png` | 真实结果页效果图 |
| `assets/02-四个关键节点.png` | 真实调查过程效果图 |
| `assets/03-证据对照.png` | 真实只读证据与失败/正常请求对照效果图 |

## 推荐提交组合

1. 方案附件：优先上传 `MateClaw智能排障-作品方案.pdf`，需要继续编辑时使用 DOCX
2. Demo：`MateClaw智能排障-作品介绍.html`
3. 效果图：`assets/` 下三张 PNG
4. 视频：按 `MateClaw智能排障-演示视频脚本.md` 录制 4 分钟屏幕演示

## 现场演示入口

本地服务启动并登录后访问：

```text
http://127.0.0.1:5173/troubleshooting?view=detail&diagnosisId=diag-acee292ecd7647288e2c39e80007ec2e
```

演示时只查看已有 Diagnosis，不点击“确认结论”，避免改变演示记录的状态。
