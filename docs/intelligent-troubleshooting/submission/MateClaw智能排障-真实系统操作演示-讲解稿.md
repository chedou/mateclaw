# MateClaw 智能排障真实系统操作演示讲解稿

对应视频：`MateClaw智能排障-真实系统操作演示.mp4`

## 演示主线

本视频使用真实排障单 `diag-acee292ecd7647288e2c39e80007ec2e`，案例为 `CSDP / csdp-wechat / ITGW访问失败【904003】`。

开场先说作品要解决的三个真实问题：二线能基于平台启动并推进标准化排障；三线开发不必先熟悉陌生系统的全部实现和观测字段，也能快速进入有效调查；重大故障中，开发团队可以围绕同一份证据快速收敛问题范围。这不是降低代码质量、生产权限或最终责任要求。

1. 从排障队列点击排障单号进入详情。
2. 查看值班人员首先需要的业务摘要、当前结论和人工处理边界。
3. 展开排障过程，用四个关键节点理解本次调查。
4. 查看失败请求和同窗口正常请求的对照结果。
5. 切换到完整七步，复核查询、取证、判据和停止条件。
6. 切换到证据关系，从结论反查规则、判据和只读证据。
7. 返回顶部，说明系统只完成只读调查，生产操作仍由授权人员执行。

收尾要明确说明：这次演示证明的是一条已审核方法能在真实 Guance 数据上跑通。二线是否能独立完成、陌生系统开发是否减少求助、重大故障是否更快收敛，还需要用真实人员试用和历史复盘数据验收。

## 演示边界

- 视频仅查看已经存在的真实 Diagnosis，没有点击“确认结论”。
- 没有展示 API Key、登录密码、原始日志正文或危险查询。
- 当前视频证明一条真实 Guance 竖线已跑通，不代表所有系统和场景已经完成投产验收。
