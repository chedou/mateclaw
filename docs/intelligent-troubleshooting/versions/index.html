v0.21 · OPEN_DISCOVERY 确定性有界调查窄线

CURRENT

冻结服务端 HypothesisGraph → BoundedInvestigationPlanner → ReadOnlyToolRegistry → RootCauseFinding 窄线。每轮只问一个已登记问题，受迭代、调用和总时长预算约束；并列原因不任选，证据不足仍保存弃权与停止原因。首个 Guance 应用错误查询按服务冻结，Kubernetes 资产缺失继续显示未记录。本版不等于通用自主规划或多 Agent 已投产，T7 仍为 0/20。

v0.20 · 证据资产授权补上场景维度

2026-08-14

图形语义延续 v0.18；RFC v4.6 / D20 给资产授权键加上服务端拥有的 scenarioKey，让一个服务可以承载多个场景的查询合同。起因是 csdp-wechat「URL 慢请求」真实告警落不了地——该服务的 log_search / log_trace_bundle / contrast_sample 已被 ITGW 904003 占满。场景来自已冻结 Playbook 而非请求参数，旧配置必须显式声明所属场景，不设通配、默认场景或隐式回退，验收指纹按场景计算。本版只发布设计，实现与旧配置迁移均未完成。
